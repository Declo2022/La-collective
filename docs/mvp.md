# MVP — 10 workflows

Périmètre resserré validé : **10 workflows**, développés un par un dans l'ordre
de priorité, chacun testé avant le suivant.

## Règles

- **Shopify en lecture seule** — aucun workflow ne modifie la boutique.
- **Validation humaine** pour toute action externe/commerciale (#7, #8) via
  Telegram (#9).
- **#10 et #9** sont le socle (sécurité + observabilité), développés en premier.
- Coût cible ~35–85 €/mois, borné par le plafond de tokens (#10).

## Ordre

Lot A : #10, #9 · Lot B : #1, #3, #2, #4 · Lot C : #5, #6 · Lot D : #8, #7.

## Décisions spécifiques

### #7 — Prospection de partenaires

- Utilise la **recherche web externe** pour trouver des prospects.
- **Enrichit** les données avec l'IA.
- Permet aussi d'**importer des listes** fournies par le fondateur.
- Aucun contact envoyé sans validation humaine (Telegram).

### #8 — Assistance service client

- Centralise les demandes depuis **Shopify, Gmail et Instagram**.
- **Aucune réponse automatique.**
- Toute réponse est **proposée à un humain pour validation avant envoi**.

## Valeur commerciale par workflow

Principe : chaque workflow doit contribuer aux ventes, directement ou en
protégeant la marge / la fiabilité.

| --- | ----------------------------------------------------------------------------- |
