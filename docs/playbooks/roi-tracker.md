# Tableau ROI — suivi des fondations e-commerce

Chaque outil a **30–60 jours pour prouver son ROI**. Ce qui ne prouve rien est
coupé ; on double ce qui marche.

## 1. Baseline (à remplir AVANT toute installation)

| Métrique                       | Valeur de départ | Date |
| ------------------------------ | ---------------- | ---- |
| CA mensuel                     |                  |      |
| Sessions / mois                |                  |      |
| Taux de conversion             |                  |      |
| Panier moyen (AOV)             |                  |      |
| Taille liste e-mail            |                  |      |
| Sessions organiques / mois     |                  |      |
| Temps de 1re réponse SAV       |                  |      |
| Taux de retour / remboursement |                  |      |

> Sans baseline, aucun ROI n'est prouvable. C'est la **première action**.

## 2. Tableau ROI par outil

| Outil     | Coût/mois | Métrique de preuve            | Cible « ça marche »     | Résultat 30 j | Résultat 60 j | Verdict |
| --------- | --------- | ----------------------------- | ----------------------- | ------------- | ------------- | ------- |
| Klaviyo   | 0–45 €    | % CA attribué                 | &gt; 15–20%             |               |               |         |
| Avis      | ~15 €     | conversion fiche +/- avis     | hausse mesurable        |               |               |         |
| Upsell    | 0–18 €    | AOV avant/après               | +5% mini                |               |               |         |
| Gorgias   | 10–30 €   | temps 1re réponse / h gagnées | réponse rapide, temps ÷ |               |               |         |
| Dashboard | ~0 €      | anomalies vues &lt; 24 h      | oui                     |               |               |         |
| SEO       | 0–29 €    | sessions & CA organiques      | tendance + à 90 j       |               |               |         |

## 3. Formules utiles

- **ROI d'un outil** = (CA additionnel généré − coût de l'outil) / coût de l'outil.
- **CA additionnel Klaviyo** = CA attribué par Klaviyo (natif, onglet Analytics).
- **Gain AOV upsell** = (AOV après − AOV avant) × nb commandes/mois.
- **Panier abandonné récupéré** = nb paniers récupérés × AOV.
- **Gain de temps Gorgias** = (temps SAV avant − après) par semaine × valeur horaire.

## 4. Rituel de suivi (hebdomadaire, 15 min)

1. Relever les métriques du tableau §2.
2. Comparer à la baseline (§1) et à la semaine précédente.
3. Décider : garder / ajuster / couper.
4. Noter la décision (date, raison).

## 5. Seuils de décision

- **Garder** : l'outil dépasse sa cible « ça marche » à 60 j.
- **Ajuster** : proche de la cible → optimiser (flows, placements, macros) avant de trancher.
- **Couper** : sous la cible à 60 j sans trajectoire d'amélioration.

## 6. Objectif de la machine

Une fois Klaviyo + upsell + avis + Gorgias prouvés (ROI positif, mesuré), les
fondations « génèrent un ROI mesurable » → **feu vert pour le chantier BUILD**
(moteur de contenu). Voir `docs/roadmap-90days.md`.
