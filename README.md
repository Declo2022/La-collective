# 🐍 Snake — La Collective

Un petit jeu Snake classique, en un seul fichier HTML. Aucune dépendance, aucune installation.

## Jouer

Ouvre simplement `index.html` dans ton navigateur.

## Commandes

- **Flèches** ou **Z / Q / S / D** (ou W/A/S/D) pour diriger le serpent
- **Espace** pour mettre en pause
- Sur mobile&nbsp;: **glisse ton doigt** dans une direction

## But

Mange les pommes 🍎 pour grandir et augmenter ton score. Le serpent accélère
au fil des points. Évite les murs et ta propre queue. Ton record est
sauvegardé localement dans le navigateur.
